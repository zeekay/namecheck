# namecheck

[![Open in Hanzo](https://hanzo.app/badges/open-in-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/namecheck&ref=master&action=open) [![Edit with Hanzo](https://hanzo.app/badges/edit-with-hanzo.svg)](https://hanzo.app/dev/open?repo=github.com/zeekay/namecheck&ref=master&action=edit)

Namecheck npm like a pro. Accepts multiple arguments. Sends `HEAD` queries to the npm registry API to check for package existence.

```sh
npm install -g namecheck # installation
namecheck node git requisite # check multiple names at once
```
